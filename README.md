📊 Project Overview

This project analyzes student performance, course engagement, and learning outcomes using an LMS (Learning Management System) dataset.
The data was cleaned and prepared using Microsoft Excel and visualized through interactive dashboards in Power BI.

The objective is to identify performance gaps, engagement patterns, and factors influencing course completion and satisfaction.

🎯 Problem Statement

Educational platforms often struggle to identify:

Low-performing courses

Poor student engagement

Assignment completion gaps

Factors affecting satisfaction ratings

This project aims to transform raw educational data into actionable insights to support data-driven academic decisions.

🛠 Tools & Technologies Used

Microsoft Excel (Data Cleaning & Preparation)

Power BI (Data Modeling & Dashboard Creation)

📂 Dataset Information

The dataset represents LMS data from 2023–2025 and includes:

Student demographics

Course details

Quiz & project performance

Assignment submission records

Progress percentage

Session duration

Satisfaction & instructor ratings

Device preferences

🧹 Data Preparation Steps

Imported dataset into Excel

Removed null and duplicate records

Standardized data types

Cleaned inconsistent values

Imported cleaned data into Power BI

Created relationships and calculated measures

📈 Dashboards Created
📌 Dashboard 1 – Student Performance Overview

Key KPIs:

Most Enrolled Course

Total Student Count

Overall Rating

Most Active Age Group

Preferred Payment Method

Insights:

Beginner-level courses show higher completion rates

Longer session duration correlates with better performance

Instructor rating strongly impacts satisfaction

📌 Dashboard 2 – Course Performance Analysis

Key KPIs:

Assignment submission trends

Instructor rating analysis

Course-level performance comparison

Insights:

High-enrollment courses have more missed assignments

Assignment completion affects final performance

Performance gaps exist across course levels

🔎 Key Insights & Recommendations
Insights:

Higher engagement leads to better quiz scores

Course difficulty impacts assignment submission

Student satisfaction is influenced by instructor rating

Recommendations:

Improve engagement strategies for popular courses

Provide additional support for advanced learners

Enhance instructor feedback systems

Optimize course structure for better completion rates
